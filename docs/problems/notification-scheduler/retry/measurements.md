# 알림 유실 측정 자료

> 본문: [알림 유실 해결기](README.md)

측정 환경과 원자료를 남긴다. 본문에는 결론만 싣고, 재현에 필요한 것은 여기에 둔다.

---

## 측정 환경

```
서버        2 vCPU / 2 GB, 단일 인스턴스
DB          MySQL 8.0
알림 건수    100건
스케줄러     @Scheduled(cron = "0 * * * * *")  매분 0초
```

---

## 발송 1건당 소요 시간

추적 로그에서 `발송시도` 와 `전송성공`/`전송실패` 사이의 간격을 잰 값.

| 상황 | 시각 | 소요 |
|---|---|---|
| 성공 | `02:55:00.022` → `02:55:00.918` | **896 ms** |
| 실패 (SENDER_ID_MISMATCH) | `23:50:00.073` → `23:50:01.578` | **1,505 ms** |
| 실패 (THIRD_PARTY_AUTH_ERROR) | `01:30:00.041` → `01:30:03.028` | **2,987 ms** |

**실패가 성공보다 2~3배 느리다.** 이 값은 [처리량 글](../throughput/)에서 다시 쓴다.

## 실험 A — 서버가 꺼진 사이

**절차**

```
1  docker compose stop app
2  reset.sql 로 알림 시각을 NOW() 로 옮긴다
3  2분 대기
4  docker compose start app
5  로그와 DB 를 5분간 관찰
```

**개선 전** — 2026-08-25 측정

알림 시각을 `17:03:41` 로 맞춘 뒤 서버를 껐고, 그 분이 지난 다음 다시 켰다.

| 항목 | 값 |
|---|---|
| 도달 | **0 / 100** |
| `is_sent = false` 로 남은 건수 | **100** |
| 울릴 시각이 지났는데 미발송 | **100** |
| 알림함에 만들어진 줄 | **0** |
| 이후 실행에서 재조회된 건수 | **0** |

로그는 재시작 이후 계속 `count=0` 이었다.

```
[ALARM] 조회 window=2026-08-25T17:05~17:06 count=0
[ALARM] 조회 window=2026-08-25T17:06~17:07 count=0
```

**알림함 줄이 0건이라는 게 핵심이다.** 알림함은 발송을 시도하기 전에 만들어지므로,
0건이라는 것은 **스케줄러가 그 알림을 집지도 않았다**는 뜻이다. 보내려다 실패한
것이 아니라 시도 자체가 없었다.

> `SUM()` 결과가 `NULL` 로 나오는 것은 셀 행이 0개이기 때문이다. 오류가 아니다.

| 항목 | 값 |
|---|---|
| 도달 | / 100 |
| 복구까지 걸린 시간 | |
| 100건 드레인 시간 | |

## 실험 B — 발송 실패 후 복구

**절차**

```
1  DELETE FROM fcm_token WHERE users_id = ?
2  reset.sql 로 알림 시각을 2분 뒤로 설정
3  발송 실패 확인
4  앱에서 재로그인해 토큰 복구
5  로그와 DB 를 5분간 관찰
```

**개선 전** — 2026-08-25 측정

토큰을 지운 뒤 알림 시각을 2분 뒤로 맞췄고, 발송 실패를 확인한 다음 앱에서
다시 로그인해 토큰을 복구했다.

| 항목 | 값 |
|---|---|
| 발송 시도 | **100 / 100** |
| 도달 | **0 / 100** |
| `is_sent = true` 로 바뀐 건수 | **100** |
| 알림함에 만들어진 줄 | **100** (전부 `sent_at` 이 `NULL`) |
| 토큰 복구 후 재시도된 건수 | **0** |

**한 건도 안 나갔는데 `is_sent` 는 전부 `true` 로 바뀌었다.** 로그에는
`발송실패` 가 100번 찍혀 있는데 DB 에는 "전부 보냄" 으로 기록된 것이다.

실험 A 와 비교하면 흔적이 정반대다.

| | 알림함 줄 | `is_sent` | 뜻 |
|---|---|---|---|
| A | 0 | `false` | 집지도 않았다 |
| B | 100 | `true` | 집어서 100번 다 실패했는데 완료로 적혔다 |

**둘 다 도달 0 인데 남은 기록이 반대다.** 유실에 이르는 입구가 다르다는 것이
데이터로 드러난다.
